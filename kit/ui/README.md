# Jai 游戏 UI

`#import "kit/ui"` 使用纯 Jai Clay 布局和 Foster 绘制。入口为 `ui_init`、`ui_begin`、
控件声明、`ui_end` 和 backend 提交；输入、文本编辑、控件、视觉样式按主题分文件。
`UI_Context` 由调用方持有并用 `ui_dispose` 释放，不在游戏之间共享可变全局状态。
字体通过 `ui_register_font` 注册；离线 MSDF 生成见 [字体工具](../../tools/fonts/README.md)，
运行时位图烘焙由 `ui_font_bake` 提供，两者不能只凭类型相同就假定采样效果相同。

## 最终像素采样与清晰度验收

- UI 在最终输出的物理像素尺寸绘制。低分辨率游戏场景单独缩放，不能连带放大 UI。
- 绘制与命中测试使用同一坐标变换；检查偏移视口、窗口 resize、系统缩放及非整数比例。
- 用最终输出检查中文/英文、小字号、描边、截断、缺字与图标隔离区，不用图集截图代替画面验收。
- 字体小字号问题、场景 3D 分辨率与 MSAA 分别检查；加粗不是修复错误采样的办法。
- 图集是 GPU 资源，按约定保持地址稳定，并在设备销毁前释放。不要把 CPU 子集字体、
  MSDF 图集或 ImGui 图集的所有权混用。
- 只有画面或输入改变时才按需截图，输出到项目 `library/screenshots`；纯文档/目录改动不截图。
